# RyanCraft Wiki

A guide to everything RyanCraft adds to Minecraft 1.21.11. Pick a topic:

| | |
|---|---|
| 🦌 **[Wildlife](Wildlife.md)** | Deer, bears, birds, ocean life and seventy-odd more animals, what they drop, and how to tame or carry them |
| 🎣 **[Fishing](Fishing.md)** | Game fish with real lengths, trophies, the Angler's Logbook and fish plaques |
| 🪖 **[Mudlings](Mudlings.md)** | Little biome soldiers: camps, teams, battles and level-ups |
| 🍲 **[Cooking and Farming](Cooking.md)** | The cooking pot, campfires that burn fuel, seasonal crops and dishes |
| 🍂 **[Seasons, Thirst and Weather](Seasons.md)** | The twelve-part year, the thirst bar, dust storms and night ambience |
| 🌳 **[Trees and Biomes](Trees.md)** | Fifteen eastern trees with full wood sets, and the forests they grow in |
| 🕳️ **[The Abyss](Abyss.md)** | A new cave layer below the deepslate: five kinds of cavern down to y=−128 |
| ⛏️ **[Ores, Metals and Gems](Ores.md)** | Silver, lead, tin, zinc, aluminum, uranium, steel, ruby, sapphire and jade |
| ⚙️ **[Machines](Machines.md)** | Pipes, engines, pumps, tanks and the Ender Terminal |
| 📦 **[Storage](Storage.md)** | Diamond, obsidian and lead glass chests, clay pots, cages and bundles |
| 💣 **[Combat](Combat.md)** | Old-style combat, cannons with six kinds of shot, and muskets |
| ☁️ **[The Skylands](Skylands.md)** | Floating islands, pegasi, rideable rocs and zephyrite gear |
| 🌕 **[The Moon](Moon.md)** | Low gravity, no air, meteors, and the Great Moon Rabbit |
| 📜 **[Recipes](Recipes.md)** | Every recipe in the mod, by category and A to Z |
| 🔧 **[Settings and Commands](Settings.md)** | The config file and every command |

Curious where it's headed? The **[concept ideas](../concept_ideas.md)** page collects the bigger ideas worked out so
far (airships, electricity, brewing, the tropics and more), with concept art.

New to the mod? Start with [Wildlife](Wildlife.md) and [Seasons](Seasons.md), which you'll notice first. Then build
a [cooking pot](Cooking.md), and when you're ready for a trip, light a [Skylands portal](Skylands.md).
